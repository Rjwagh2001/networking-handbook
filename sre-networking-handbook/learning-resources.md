# Learning Resources

Use these resources in the sequence below. The practical exercises and notes for each session will be added to the corresponding folder after studying the material.

> Video titles, URLs, and availability can change. Confirm the exact session and duration when opening a resource.

## Session 01 — Networking fundamentals

**Instructor:** Abhishek Veeramalla  
**Planned focus:** OSI and TCP/IP models, packets, IP addressing, CIDR, subnetting, routing and basic networking concepts.

- [Networking fundamentals session](https://www.youtube.com/watch?v=iSOfkw_YyOU)

## Session 02 — Linux networking

**Resource:** Linux Foundation session featuring Muna Nwaiwu (Google)  
**Planned focus:** Linux network interfaces, routes, sockets and practical troubleshooting.

- [Linux Networking: Key Understanding and Practical Troubleshooting](https://www.classcentral.com/course/youtube-linux-networking-key-understanding-and-practical-troubleshooting-muna-nwaiwu-google-464530)

## Session 03 — Practical Networking

**Resource:** Practical Networking  
**Planned focus:** Reinforce IP addressing, subnetting, routing and packet flow. Use selected lessons only where a concept needs more explanation.

- [Practical Networking YouTube channel](https://www.youtube.com/@PracticalNetworking)

## Session 04 — DNS, TCP, HTTP and TLS

**Resource:** Cloudflare Learning Center  
**Planned focus:** DNS resolution, TCP connections, HTTP/HTTPS, TLS and how browser requests work.

- [Cloudflare Learning Center](https://www.cloudflare.com/learning/)

## Session 05 — AWS networking

**Resource:** AWS networking fundamentals  
**Planned focus:** VPC, CIDR, public/private subnets, route tables, Internet Gateway, NAT Gateway, security groups, Network ACLs, ALB and NLB.

- [AWS Networking Fundamentals video](https://www.youtube.com/watch?v=hiKPPy584Mg)
- [AWS Networking and Content Delivery](https://aws.amazon.com/products/networking/)
- [Amazon VPC documentation](https://docs.aws.amazon.com/vpc/latest/userguide/what-is-amazon-vpc.html)

## Session 06 — Kubernetes networking

**Resource:** Linux Foundation Kubernetes networking session  
**Planned focus:** Pod networking, CNI, Services, kube-proxy, CoreDNS, Ingress and NetworkPolicy.

- [Kubernetes networking session](https://www.youtube.com/results?search_query=Linux+Foundation+Understanding+the+Kubernetes+Networking+Layer)
- [Kubernetes — Cluster Networking](https://kubernetes.io/docs/concepts/cluster-administration/networking/)
- [Kubernetes — Services and Load Balancing](https://kubernetes.io/docs/concepts/services-networking/)
- [Kubernetes — DNS for Services and Pods](https://kubernetes.io/docs/concepts/services-networking/dns-pod-service/)
- [Kubernetes — Network Policies](https://kubernetes.io/docs/concepts/services-networking/network-policies/)

## How to use these resources

1. Watch the assigned session.
2. Record the topics actually covered; do not assume every topic in the roadmap is covered by the video.
3. Share your notes and questions for practical follow-up.
4. Add validated explanations and lab results to this repository.
5. Use official documentation to verify implementation details.
