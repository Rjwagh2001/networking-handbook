# 01 — Networking Fundamentals

**Learning session:** Abhishek Veeramalla — see [`../learning-resources.md`](../learning-resources.md).

## Objectives

- Explain why networks and protocols are needed.
- Describe the OSI and TCP/IP models.
- Understand packets, frames, IP addresses and MAC addresses.
- Distinguish private and public IP addresses.
- Understand CIDR, subnet masks, default gateways, routers and switches.
- Describe the basic path a request takes from a client to a remote service.
