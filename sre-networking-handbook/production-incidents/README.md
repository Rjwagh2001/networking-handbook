# Production-Style Network Incidents

These are controlled learning scenarios, not claims about incidents at any specific company. Reproduce failures only in a disposable lab or an environment you are authorized to test.

## Incident exercises

1. [Application timeout / HTTP 504](incident-01-application-timeout.md)
2. [Application cannot connect to database](incident-02-database-connectivity.md)
3. [Kubernetes Service failure](incident-03-kubernetes-service-failure.md)
4. [DNS resolution failure](incident-04-dns-resolution-failure.md)
5. [High network latency](incident-05-high-network-latency.md)

For every incident, capture evidence and distinguish confirmed facts from hypotheses.
