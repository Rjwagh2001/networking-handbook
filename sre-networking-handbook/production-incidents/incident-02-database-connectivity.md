## Scenario

An application cannot establish a connection to its database.

## Investigation checklist

- [ ] Verify database hostname resolution.

- [ ] Test connectivity from the application host or Pod.

- [ ] Review Security Groups, Network ACLs and host firewalls.
- [ ] Check database availability and connection limits.
